The short version.

I'm a research engineer working on computer vision and MLOps. At Vivid Machines in Toronto, most of my work is getting large vision models to run well on small hardware. I distill them, calibrate their predictions, and ship them as optimized TensorRT graphs that run on camera.

Before that I did my M.Sc. at Mila, Université de Montréal, in the program supervised by Prof. Yoshua Bengio, and worked at CRIM on diffusion models for deepfake detection. I have co-authored three peer-reviewed papers on vision transformers and diffusion models.

I started out as a software engineer in India, building ML and .NET systems at L&T Infotech and Wipro.

Side projects.

Physically based renderingFall 2026

A Monte Carlo path tracer in Python

A vectorised path tracer written in NumPy, with drop-in CuPy (CUDA) and MLX (Apple Silicon) backends. It renders global illumination with implicit BRDF-sampled paths and with explicit paths using next-event estimation, plus direct lighting under four sampling strategies, including multiple importance sampling, and ambient occlusion. Integrators, scenes, samplers and denoisers are plug-ins, and a desktop app shows the render converging pass by pass.

The Cornell box shown here is rendered by a real path tracer running in your browser, with next-event estimation. 0 samples per pixel so far.

Repository on GitHub
